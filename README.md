# Agent Skills

A collection of agent skills I use every day for real engineering — not vibe coding.

Each skill is a small, focused `SKILL.md` that teaches your coding agent how to perform one task well. Install the whole collection or pick individual skills.

## Installation

```bash
npx skills add <your-username>/skills
```

Pick the skills you want when prompted, or install specific ones:

```bash
npx skills add <your-username>/skills --skill git-micro-commit -a claude-code
```

## Skills

| Skill | Category | Description |
|-------|----------|-------------|
| `git-micro-commit` | engineering | Make tiny, single-purpose git commits — one file or one logical change at a time — following Conventional Commits. |

## Updating

```bash
npx skills update
```
